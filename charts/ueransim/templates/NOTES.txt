ueransim successfully installed!

start gnb with open5gs-gnb.yaml config file:
```
kubectl exec -it <gnb_pod_name> -n <namespace_name> bash
cd ueransim/
./nr-gnb -c config/open5gs-gnb.yaml
```

start UE with open5gs-ue.yaml config file:
```
kubectl exec -it <ue_pod_name> -n <namespace_name> bash
cd UERANSIM/
./nr-ue -c config/open5gs-ue.yaml
```

There is a tun interface for each ue. 
You can bind your application to the interface to test ue connectivity.
Example:

```
ping -I uesimtun0 example.com
traceroute -i uesimtun0 example.com
curl --interface uesimtun0 https://example.com/ 
```
